SI 1. Technical information about the TMFG algorithm (Massara et al., 2016)

The TMFG algorithm starts from a clique of order 4 (K4 ) and adds nodes in the middle of a 3-
clique (T2 move). At each step, the algorithm optimizes the sum of the weights of the edges. T2
is applied to the vertex and face pair that leads to the maximum increase in weights.

  TMFG Algorithm:
  input :A dense n×n square matrix W with positive weights
  output: A sparse matrix, P, a filtered version of W fulfilling the planarity
  constraint
  1. C1 ←Tetrahedron, {v1,v2,v3,v4}, with highest overall total weights; // Assign the four
  triangular faces in C1 to the array T
  2. T ← {{v1,v2,v3},{v1,v2,v4},{v1,v3,v4},{v2,v3,v4}}; // Put the p − 4 vertices not belonging to
  C1 in the array V
  3. V← v5,···,vp ; // Create an empty list of Separators

  4.     S← ∅; // Assign the first tetrahedron to the list of cliques
  5. C ← C1;
  6. P ← W(C1,C1);
  7. Calculate MaxGain for T and V as in Eq.(1) ;
  8. Calculate BestVertex for T and V as in Eq. (2) ; // Insert p − 4 vertices via T2
  9. while V is not empty do
  10.    Find the ti ∈ T and vi ∈ V that achieve the maximum in MaxGain ;
  11.    Insert vi into ti // this creates three new triangles ta, tb, tc
  12.    V ← V \ vi ;
  13.    T ← (T \{ti})∪{ta,tb,tc};
  14.    Si ←{ti};
  15.    S ← S ∪ Si;
  16.     Ci ←{ti,ta,tb,tc};
  17.     C ← C ∪ Ci;
  18.    P ← P + W (Ci , Ci ) − W (Si , Si );
  19.    Update MaxGain and BestVertex to reflect the changes in T and V ;
  20.    end
  21.    return P;
